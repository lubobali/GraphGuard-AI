# Recording tips (S8b.6)

1. **Loom** (free): Screen + Mic. Camera off. "Full screen", not one tab, so the clicks show.
2. **A new Chrome Incognito window for every try** (Cmd + Shift + N), one tab:
   https://graphguard.lubobali.com. The site remembers your decisions in the browser, so an
   old window would show your practice decisions. Incognito starts clean. Dark is the default.
3. **Zoom 110%** (Ctrl/Cmd and +) so the text is big enough on a phone.
4. **Hide** the bookmarks bar (Ctrl/Cmd + Shift + B) and close chats and email: no pop-ups.
5. **Do one practice run** without recording. The clicks: home (point at the numbers) → scroll
   to the list → #11 → Play all → Suspicious, type the reason, Submit → View as Reviewer → #10
   → type the note, Send back → View as Manager → Backlog → Plan the team → GraphGuard (top left).
6. **Close the practice window**, open a new Incognito window, and start recording there.
7. **Mic**: quiet room, laptop mic is fine; headphones with a mic are better.
8. **Speed**: slow. Pauses are good; the screen needs time to move.
9. **Take 2 or 3 tries** and keep the best. Small mistakes sound real; don't chase perfect.
10. Send me the Loom link: I check every number against the script before it goes on the website.
